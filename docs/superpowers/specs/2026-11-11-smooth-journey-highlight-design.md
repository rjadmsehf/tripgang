# 여행 하이라이트 요약 재생, 비행기 250km/h 모션, 날짜 선택 및 대형 지도 설계 (Smooth Journey Highlight Design)

## 1. 개요 (Overview)
실제 24시간 실시간 비율 재생 시 발생하는 야간 수면/장시간 정지 공백으로 인한 멈칫거림을 없애고, 실제 이동 경로를 따라 매끄럽게 물 흐르듯 이어지는 "여행 하이라이트 요약 타임랩스"를 구현한다. 비행기는 시속 250km/h 이상으로 엄격화하고, 날짜 선택 기능(전체 + 개별 일자), 도보 이동 뚜렷한 색상 표시, 대형 와이드 지도 뷰를 적용한다.

---

## 2. 세부 사양 (Specifications)

### 2.1 이동 중심 부드러운 하이라이트 재생 (Smooth Motion)
- **시간 공백 압축**: 24시간 실시간 타임스탬프 비례 대신, 실제 이동 지점(waypoint)과 거리 가중치를 기반으로 보간하여 정지/수면 시간의 불필요한 멈춤 없이 경로를 따라 유려하게 이동.
- **날짜 중심 표시**: 초/분 시계 대신 `Day 1 · 05.01`, `Day 2 · 05.02` 등 직관적인 날짜 배너 오버레이 표시.

### 2.2 비행기 모션 기준 250km/h 이상
- 두 지점 간 계산 속도 > 250 km/h (약 70 m/s) 또는 직선거리 > 100km인 경우 비행기(`FLYING`)로 판정.
- 비행기 구간에서는 ✈️ 아이콘이 비행 방향(Bearing) 각도로 회전하고, 속도를 0.25x로 자동 감속하여 하늘을 날아가는 모습이 뚜렷이 보이도록 연출.

### 2.3 날짜 선택 기능 (어지러움 방지)
- 사이드바 또는 상단에 날짜 선택 셀렉터 배치:
  - `ALL`: 전체 여행 일정 요약 보기
  - `Day 1 (YYYY-MM-DD)`: 1일차 이동 경로만 단독 표시 & 재생
  - `Day 2 (YYYY-MM-DD)`: 2일차 이동 경로만 단독 표시 & 재생...
- 특정 날짜 선택 시 지도 경로(Polylines)와 통계가 해당 일자만 필터링되어 복잡함 해소.

### 2.4 지도 화면 크기 대폭 확장
- `.timeline-sidebar`: 폭을 280px~300px로 슬림하게 최적화.
- `.timeline-container`: 화면 가로폭과 세로폭을 최대화 (`height: calc(100vh - 90px)`), 오른쪽 약간의 여백만 두고 지도가 화면 대부분을 차지하는 시원한 뷰포트 제공.
- 맵 로드 시 `invalidateSize` 적용.

### 2.5 걷기(도보) 확실한 시각화
- 시속 7km/h 이하의 이동은 `WALKING`으로 완벽 분류.
- 도보 경로는 형광 민트/에메랄드(`--accent-teal: #2dd4bf`) 색상으로 눈에 띄게 렌더링.

## 3. 변경 대상 파일
- `src/services/timelineParser.js`: 속도 250km/h 이상 비행기 판정 로직, 도보 판정 보강, 일자별 인덱싱 지원.
- `src/components/TimelineVisualizer.jsx`: 날짜 선택 state(`selectedDayFilter`), 거리 기반 하이라이트 재생 엔진, 비행기 각도 및 감속 연출, 날짜 단위 뱃지.
- `src/components/TimelineVisualizer.css`: 와이드 지도 레이아웃, 슬림 사이드바, 날짜 뱃지 디자인.
