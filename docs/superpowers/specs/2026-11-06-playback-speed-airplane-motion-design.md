# 타임라인 재생 속도 감속, 비행기 비행 모션 및 UI 안정화 설계 (Playback Speed, Airplane Motion, & UI Stabilization Design)

## 1. 개요 (Overview)
전체 여행 일정이 길어짐에 따라 타임라인 재생이 너무 빠르게 끝나는 문제를 해결하기 위해 기본 재생 속도를 대폭 감속하고 세분화된 배속 옵션을 제공한다. 또한 UI 텍스트 변경에 따른 컨트롤 바 밀림 현상을 고정폭 그리드로 고정하고, 재생/일시정지 버튼의 시각적 디자인을 강화하며, 장거리 비행기 구간의 비행 방향 회전 각도 및 감속 비행 모션을 구현한다.

---

## 2. 세부 요구사항 및 UX 개선 (Detailed Requirements)

### 2.1 재생 속도 감속 및 시간 연장
1. **기본 배속 및 스케일 조정**:
   - `speedMultiplier` 기본값을 `1`로 설정 (기존 5에서 변경).
   - 기본 완주 소요 시간 기준을 기존 약 20초에서 60~90초로 여유 있게 스케일링.
   - 재생 속도 옵션:
     - `0.25x` (매우 느리게 - 긴 여행 정밀 감상)
     - `0.5x` (느리게)
     - `1x` (보통 · 기본값)
     - `2x` (빠르게)
     - `4x` (매우 빠르게)
2. **동영상/GIF 내보내기 길이 옵션 확장**:
   - 기존: 15초, 30초, 45초, 60초
   - 신규: 30초, 60초, 90초, 120초(2분) 지원으로 긴 여행도 넉넉한 분량의 애니메이션으로 제작 가능.

### 2.2 재생 / 정지 버튼 시각 디자인 강화
- 단순한 회색 원형 버튼에서, 선명한 상태 표시(▶️ 재생 중이 아닐 때 "재생" 라벨과 에메랄드/그린 그라데이션, ⏸️ 재생 중일 때 "일시정지" 라벨과 세련된 인디고/퍼플 그라데이션)를 갖춘 버튼으로 개선.

### 2.3 레이아웃 밀림(Jitter / Shift) 방지
- 하단 재생 표시기(`current-playback-indicator`):
  - `font-variant-numeric: tabular-nums` 적용 (숫자 폭 고정).
  - 날짜(`MM.DD`), 시간(`HH:mm`), 수단 뱃지(`🚗 자동차` 등)를 독립된 고정 너비 서브 엘리먼트로 분리 배치하여, 텍스트가 바뀔 때 전체 바의 너비가 1px도 흔들리지 않도록 고정.

### 2.4 장거리 비행기 비행 모션 및 감속 연출
1. **비행 구간 판별**:
   - `pt.type === 'FLYING'` 또는 두 좌표 간 거리가 50km 이상인 구간.
2. **비행 방향(Heading / Bearing) 각도 계산**:
   - `calculateBearing(lat1, lon1, lat2, lon2)` 함수 구현.
   - 비행기 아이콘(✈️)을 진행 각도에 맞춰 회전(`transform: rotate(${bearing}deg)`).
3. **비행 구간 감속 연출**:
   - 비행 중인 프레임에서는 재생 진행 속도를 자동으로 0.4x~0.5x 수준으로 부드럽게 감속하여 비행기가 대륙/바다를 가로지르는 장면이 시각적으로 명확히 전달되도록 연출.
